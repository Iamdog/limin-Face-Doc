# Java 后端与全栈架构前言

Java 是工业级企业后端与全栈架构的基石。本专栏拒绝流于表面的八股文背诵，坚持**“底层原理剖析 + 可运行代码验证 + 生产避坑实战”**。

## 核心技术矩阵（父子级架构）

```text
Java后端/
├── 1. Java 核心与底层
│   ├── Java基础与集合源码       (hashCode契约踩坑、HashMap并发覆盖写、ConcurrentHashMap演进)
│   ├── JMM并发编程与线程池     (volatile指令重排实战捕获、生产级自定义线程池调优)
│   └── JVM底层原理与调优实战    (双亲委派与破坏、Heap OOM 生产级 Dump 抓取排查)
├── 2. Spring 生态
│   ├── Spring核心与事务失效实战 (@Transactional 内部自调失效复现与 AOP 代理修复)
│   ├── AOP底层原理与三级缓存    (JDK动态代理原生代码、三级缓存为什么不能省第三级)
│   └── SpringBoot自动装配机制   (@EnableAutoConfiguration 源码流程与自定义 Starter)
└── 3. 持久层框架 (MyBatis)
    ├── MyBatis核心原理与插件实战 (MapperProxy动态代理机制、手写慢SQL拦截告警插件)
    └── MyBatis缓存与SQL注入防范  (#{}与${}底层区别、SQL注入复现、二级缓存分布式大坑)
```
