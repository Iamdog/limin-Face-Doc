# Java 后端

这里按一条真实请求的完整旅程组织 Java 后端内容：从 Java 语言和运行时开始，经过 Spring Boot、参数校验、权限、事务和 MyBatis，再按实际问题进入 Redis、消息队列、RPC、并发和生产治理。

## 先去哪里

- **从零开始**：读 [Java 后端学习地图](/doc/Java/后端学习地图)，从“语言与运行时底座”开始。
- **已经会 CRUD**：从 [CRUD 之后的后端补强路线](/doc/Java/CRUD之后的后端补强路线) 开始，先补事务、权限、并发更新和排错。
- **想跑一个完整例子**：打开 [可运行的后端练习项目](/examples/java-backend-workshop/README)，用测试和 HTTP 请求验证结论。
- **准备面试**：按学习地图的“面试与分布式”入口阅读，再回到具体专题补原理。
- **遇到线上问题**：先看 [高并发大数据与线上疑难故障排查](/doc/Java/高并发大数据与线上疑难故障排查实战)，再跳到对应中间件专题。

## 这个模块的边界

Java 模块负责 Java 代码、Spring 生态、MyBatis、缓存、消息、RPC、并发、JVM 和应用侧排错。MySQL 原理、系统设计题、容器运维和全栈安全分别由相邻模块负责，入口和关系已整理在 [Java 后端学习地图](/doc/Java/后端学习地图)。

## 阅读约定

每个专题都按“用途 → 最小使用 → 场景边界 → 排错与优化 → 原理 → 方案取舍”推进。阅读时至少跑通一个正常案例，再验证一个失败案例，并保留命令、测试、日志或响应中的一种证据。
