# Face-Doc 技术演进与全栈架构沉淀

欢迎来到 **Face-Doc**。本知识库致力于打造覆盖 **客户端（Android/Flutter）+ Web前端（Vue）+ 服务端（Java/Spring/MyBatis）+ 数据库（MySQL）+ 中间件（Redis/MQ）+ 全栈高并发与AI实战** 的全栈体系化知识图谱。

本专栏坚持三大原则：
1. **源码级深挖**：拒绝只背名词和概念，深入执行链路与底层数据结构。
2. **代码可验证**：核心机制均附带可直接运行的测试用例、复现代码与压测排查逻辑。
3. **贴合工程落地与生产场景**：直击核心技术痛点、深水区排障与一线业务实操。

## 知识库全栈导航

- 💡 **大前端全栈通俗心智模型**：专为大前端定制的后端技术同构思维映射表、电商秒杀“立即抢购”全栈全链路、快餐厅故事秒懂 MySQL（BufferPool/RedoLog/B+树）、集装箱码头搞懂 Docker/K8s、生活化趣解缓存穿透击穿雪崩。

- 📱 **移动端与跨端框架（Android / Flutter / RN / uni-app）**：四大组件、事件分发、RecyclerView 源码、协程、Kotlin底层与Compose性能调优、三大主流跨端框架架构设计（uni-app双线程与UTS、RN新架构JSI+Fabric、Flutter自绘Impeller）与技术选型决策树。
- 🌐 **Web 前端（Vue 3）**：组合式 API、响应式原理、Pinia 持久化、VueUse 高频工具、Axios 强类型网络层、Vite 生产分包构建优化。
- ☕ **Java 后端核心**：`hashCode` 契约、`HashMap` 并发覆盖写、`volatile` 重排复现、AQS、生产级线程池调优、JVM 类加载与 Heap OOM 诊断。
- 🍃 **Spring 生态**：`@Transactional` 事务失效 5 大场景、AOP 动态代理（JDK vs CGLIB）、三级缓存解决循环依赖、Spring Boot 自动装配原理。
- ⚡ **MyBatis 框架**：Mapper 动态代理执行链路、`#{}` vs `${}` 与 SQL 注入攻防、一二级缓存生产大坑、自定义慢 SQL 监控插件。
- 🚀 **高并发中间件（Redis & MQ）**：缓存穿透/击穿/雪崩生产防线、逻辑过期时间防击穿、Canal 监听 Binlog 双写一致性、RabbitMQ 死信延迟队列关单、消费幂等性。
- 🗄️ **MySQL 数据库**：基础 DDL/DML 与深分页优化、多表关联（INLJ/BNL/Hash Join 底层算法与小表驱动大表）、窗口函数 Top N、B+ 树与 8 大索引失效场景、MVCC 事务隔离与死锁排查、高并发大字段（TEXT/BLOB/JSON）行溢出与冷热分离垂直建表军规。
- 🌐 **全栈高并发实战场景**：GB 级大文件分片上传与断点续传（并发池控制）、大模型 SSE 流式打字机交互（Fetch Stream 与 AbortController 中断）、时间戳+Nonce+Sign 接口防重放防篡改与 XSS/CSRF 攻防。
- 🌍 **网络与通信协议**：TCP 三次握手/四次挥手、海量 TIME_WAIT/CLOSE_WAIT 故障排查、HTTPS TLS 1.3、移动端 SSL Pinning 证书锁定防抓包、跨域 CORS 预检缓存优化、HTTP/2 多路复用与 HTTP/3 QUIC 队头阻塞解决。
- 🐳 **DevOps 与容器工程化**：Dockerfile 多阶段构建（1GB 镜像精简至 80MB）、`docker-compose.yml` 本地一键编排启动（MySQL+Redis+后端+前端Nginx）、GitHub Actions 自动化 CI/CD。
