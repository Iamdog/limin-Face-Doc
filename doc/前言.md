# 前言

这里整理的是我在全栈技术学习与实践中的一些笔记，按专题归档、持续补充。内容并不全面，也难免有疏漏和理解不到位的地方，欢迎指正交流。

大致涉及移动端、Web 前端、后端与中间件、数据库、系统设计与工程实践，具体以左侧目录为准；各专题的「前言」里附了建议的阅读顺序，按需挑着看即可。


## 从基本使用开始

推荐先查看 [知识库检查与分层学习地图](/doc/知识库检查与分层学习地图)，按 **解决什么问题 → 基本使用 → 常见场景 → 排错与优化 → 原理与源码 → 面试取舍** 学习。

各模块的前言和专题使用入口已经连接基础实践。跨模块补充见 [算法实践](/doc/基础能力/数据结构算法与面试实践) 和 [测试与工程交付](/doc/基础能力/测试设计与工程交付)，原有文章的检查记录见 [逐篇清单](/doc/专题逐篇检查清单)。
