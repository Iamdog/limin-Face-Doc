# 面试考点覆盖复查报告（第二轮：知识点与主流面试题匹配度）

## 复查口径

上一轮（[知识库检查与分层学习地图](/doc/知识库检查与分层学习地图)）解决的是学习结构：每篇按"解决问题 → 基本使用 → 常见场景 → 排错优化 → 原理源码 → 取舍深入"六层重排，并纠正了 16 处绝对化/错误表述。这一轮只回答另一个问题：知识点本身选得对不对、全不全，是否踩中 2025–2026 市面主流面试题库。

方法：对全库 176 篇逐一提取知识点大纲（二级/三级标题），按板块与主流八股、场景题、源码题清单做覆盖比对，再对疑点全文检索二次确认（区分"有专章"与"顺带提及"）。本轮为只读审计，未改动任何技术内容。

五维定义：

| 维度 | 判断标准 |
|---|---|
| 利于学习 | 有前置、有最小示例、按层递进、能自测 |
| 利于使用 | 有真实场景、失败路径、可落地的命令/配置/清单 |
| 利于深入 | 有原理/源码解释"为什么"，能撑住三连追问 |
| 全面性 | 该方向公认知识域是否有专章 |
| 面试主流匹配度 | 市面高频题（八股+场景题+手写题）的命中率 |
