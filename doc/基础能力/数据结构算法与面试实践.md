# 数据结构算法与面试实践

## 解决什么问题

数据结构决定数据怎样存、怎样查；算法决定时间和空间成本。业务开发中去重、分页、缓存淘汰、依赖排序、并发队列都需要这些基础。先会选和用，再证明复杂度。

## 基本使用：找到和为目标的两个元素

```js
function twoSum(nums, target) {
  const seen = new Map()
  for (let i = 0; i < nums.length; i++) {
    const other = target - nums[i]
    if (seen.has(other)) return [seen.get(other), i]
    seen.set(nums[i], i)
  }
  return null
}
console.assert(JSON.stringify(twoSum([3, 3], 6)) === '[0,1]')
console.assert(twoSum([], 1) === null)
```

先说输入、输出、无解约定和是否可重复使用同一元素。这里先查再存，支持重复数值且不会使用同一位置两次；平均时间 O(n)，额外空间 O(n)。暴力双循环为 O(n²)，适合先证明正确性。

## 核心知识与练习顺序

| 结构或方法 | 解决的问题 | 必做练习 | 深入边界 |
|---|---|---|---|
| 数组、字符串 | 顺序访问和原地处理 | 双指针去重、反转、滑动窗口 | 索引边界、Unicode、可变性 |
| 哈希表、集合 | 快速查找和去重 | 两数之和、词频、分组 | 平均 O(1) 有前提；冲突与扩容 |
| 链表 | 节点插删 | 反转、环检测、合并 | 空链、单节点、指针更新次序 |
| 栈、队列 | 最近状态和先来先服务 | 有效括号、单调栈、BFS | 栈/队列不是线程安全保证 |
| 二分查找 | 有序空间定位 | lower_bound、旋转数组 | 循环不变量和左右边界 |
| 树、堆 | 层级、优先级、Top K | 遍历、最大深度、堆取前 K | BST 不保证平衡；深递归有栈风险 |
| 图 | 依赖和可达性 | BFS/DFS、拓扑排序 | 环检测、访问标记、断开的子图 |
| 排序 | 按规则组织数据 | 合并区间、稳定排序 | O(n log n)、稳定性、额外空间 |
| 回溯 | 枚举可行组合 | 子集、排列 | 撤销选择、剪枝、指数复杂度 |
| 动态规划 | 重复子问题和最优子结构 | 爬楼梯、背包、编辑距离 | 状态、转移、初值、遍历顺序 |

## 从题目到工程

LRU 可由哈希表加双向链表实现平均 O(1) 访问和淘汰，但线上缓存还要限制容量、处理并发和统计命中率。启动任务依赖可用有向无环图表示，拓扑排序检测是否有环。Top K 可用大小为 K 的堆，使扫描成本为 O(n log K)。

## 面试答题和验证

每题按输入约束 → 暴力解 → 改进思路 → 代码 → 边界测试 → 复杂度进行。至少覆盖空输入、单元素、重复值、无解、极端范围，说明是否修改原数组。不要把“背出代码”当成掌握，要能解释循环每一步维护了什么事实。

进阶包括并查集、最短路、前缀树和字符串匹配；根据目标岗位和业务需要继续学习，本页是基础训练入口。
