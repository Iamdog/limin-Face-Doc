# 数据结构算法与面试实践

## 解决什么问题

数据结构决定数据怎样存、怎样查；算法决定时间和空间成本。业务开发中去重、分页、缓存淘汰、依赖排序、并发队列都需要这些基础。先会选和用，再证明复杂度。

## 基本使用：找到和为目标的两个元素

```js
function twoSum(nums, target) {
  const seen = new Map()
  for (let i = 0; i < nums.length; i++) {
    const other = target - nums[i]
    if (seen.has(other)) return [seen.get(other), i]
    seen.set(nums[i], i)
  }
  return null
}
console.assert(JSON.stringify(twoSum([3, 3], 6)) === '[0,1]')
console.assert(twoSum([], 1) === null)
```

先说输入、输出、无解约定和是否可重复使用同一元素。这里先查再存，支持重复数值且不会使用同一位置两次；平均时间 O(n)，额外空间 O(n)。暴力双循环为 O(n²)，适合先证明正确性。

## 面试算法 MVP：先掌握这 8 个高频模板

下面的例子不是为了刷题数量，而是用最小集合覆盖 Java、Android、Vue 面试中反复出现的思路。每题都按“题意 → 思路 → 代码 → 边界 → 复杂度”练习；把 `console.assert` 换成 Java 的 JUnit、Android 的单元测试或 Vue 项目里的 Vitest 即可复用。

### 1. 哈希表：词频统计

输入一段字符串，返回出现次数最多的字符；空字符串返回 `null`。

```js
function mostFrequentChar(text) {
  if (text.length === 0) return null
  const counts = new Map()
  let answer = null
  let max = 0
  for (const char of text) {
    const count = (counts.get(char) || 0) + 1
    counts.set(char, count)
    if (count > max) {
      max = count
      answer = char
    }
  }
  return answer
}
console.assert(mostFrequentChar('abac') === 'a')
console.assert(mostFrequentChar('') === null)
```

平均时间 O(n)，空间 O(k)；相同最高频率时保留先达到最高频率的字符。

### 2. 双指针：原地移动零

把数组中的 `0` 移到末尾，保持非零元素相对顺序。

```js
function moveZeroes(nums) {
  let write = 0
  for (const value of nums) {
    if (value !== 0) nums[write++] = value
  }
  while (write < nums.length) nums[write++] = 0
  return nums
}
console.assert(JSON.stringify(moveZeroes([0, 1, 0, 3])) === '[1,3,0,0]')
```

时间 O(n)、额外空间 O(1)。要主动说明：这个版本会修改原数组。

### 3. 滑动窗口：最长无重复子串

```js
function lengthOfLongestSubstring(text) {
  const last = new Map()
  let left = 0
  let answer = 0
  for (let right = 0; right < text.length; right++) {
    const previous = last.get(text[right])
    if (previous !== undefined && previous >= left) left = previous + 1
    last.set(text[right], right)
    answer = Math.max(answer, right - left + 1)
  }
  return answer
}
console.assert(lengthOfLongestSubstring('abcabcbb') === 3)
console.assert(lengthOfLongestSubstring('') === 0)
```

窗口 `[left, right]` 始终没有重复字符，时间 O(n)、空间 O(k)。

### 4. 栈：有效括号

```js
function isValidBrackets(text) {
  const pairs = new Map([[')', '('], [']', '['], ['}', '{']])
  const stack = []
  for (const char of text) {
    if ('([{'.includes(char)) stack.push(char)
    else if (pairs.has(char) && stack.pop() !== pairs.get(char)) return false
  }
  return stack.length === 0
}
console.assert(isValidBrackets('([])') === true)
console.assert(isValidBrackets('([)]') === false)
```

每个左括号入栈、右括号匹配栈顶；时间和空间都是 O(n)。

### 5. 二分查找：找第一个不小于目标的位置

```js
function lowerBound(nums, target) {
  let left = 0
  let right = nums.length
  while (left < right) {
    const middle = left + Math.floor((right - left) / 2)
    if (nums[middle] < target) left = middle + 1
    else right = middle
  }
  return left
}
console.assert(lowerBound([1, 2, 2, 4], 2) === 1)
console.assert(lowerBound([1, 2, 2, 4], 5) === 4)
```

循环不变量是“答案始终在 `[left, right)` 中”，时间 O(log n)、空间 O(1)。

### 6. 链表：反转链表

```js
function reverseList(head) {
  let previous = null
  let current = head
  while (current) {
    const next = current.next
    current.next = previous
    previous = current
    current = next
  }
  return previous
}
```

面试时画出 `previous → current → next` 三个指针的变化；时间 O(n)、空间 O(1)。

### 7. 树：二叉树层序遍历

```js
function levelOrder(root) {
  if (!root) return []
  const result = []
  const queue = [root]
  for (let head = 0; head < queue.length;) {
    const levelEnd = queue.length
    const level = []
    while (head < levelEnd) {
      const node = queue[head++]
      level.push(node.value)
      if (node.left) queue.push(node.left)
      if (node.right) queue.push(node.right)
    }
    result.push(level)
  }
  return result
}
```

队列先进先出；每个节点只进出一次，时间 O(n)、空间 O(n)。图的 BFS 只需要再加一个 `visited` 集合。

### 8. 动态规划：爬楼梯

```js
function climbStairs(n) {
  if (n <= 2) return n
  let previous = 1
  let current = 2
  for (let step = 3; step <= n; step++) {
    ;[previous, current] = [current, previous + current]
  }
  return current
}
console.assert(climbStairs(4) === 5)
```

状态是“到第 `n` 阶的方法数”，转移为 `dp[n] = dp[n - 1] + dp[n - 2]`；滚动变量把空间从 O(n) 降到 O(1)。

### 高频题的统一答题顺序

1. 先确认输入是否有序、是否允许修改、是否允许重复使用元素。
2. 先给出能证明正确的解法，再说如何用哈希、双指针、二分或动态规划优化。
3. 用一个正常样例和一个边界样例走一遍指针或状态变化。
4. 最后说时间、额外空间和方案代价，不能只说“很快”。

## 核心知识与练习顺序

| 结构或方法 | 解决的问题 | 必做练习 | 深入边界 |
|---|---|---|---|
| 数组、字符串 | 顺序访问和原地处理 | 双指针去重、反转、滑动窗口 | 索引边界、Unicode、可变性 |
| 哈希表、集合 | 快速查找和去重 | 两数之和、词频、分组 | 平均 O(1) 有前提；冲突与扩容 |
| 链表 | 节点插删 | 反转、环检测、合并 | 空链、单节点、指针更新次序 |
| 栈、队列 | 最近状态和先来先服务 | 有效括号、单调栈、BFS | 栈/队列不是线程安全保证 |
| 二分查找 | 有序空间定位 | lower_bound、旋转数组 | 循环不变量和左右边界 |
| 树、堆 | 层级、优先级、Top K | 遍历、最大深度、堆取前 K | BST 不保证平衡；深递归有栈风险 |
| 图 | 依赖和可达性 | BFS/DFS、拓扑排序 | 环检测、访问标记、断开的子图 |
| 排序 | 按规则组织数据 | 合并区间、稳定排序 | O(n log n)、稳定性、额外空间 |
| 回溯 | 枚举可行组合 | 子集、排列 | 撤销选择、剪枝、指数复杂度 |
| 动态规划 | 重复子问题和最优子结构 | 爬楼梯、背包、编辑距离 | 状态、转移、初值、遍历顺序 |

## 从题目到工程

LRU 可由哈希表加双向链表实现平均 O(1) 访问和淘汰，但线上缓存还要限制容量、处理并发和统计命中率。启动任务依赖可用有向无环图表示，拓扑排序检测是否有环。Top K 可用大小为 K 的堆，使扫描成本为 O(n log K)。

## 面试答题和验证

每题按输入约束 → 暴力解 → 改进思路 → 代码 → 边界测试 → 复杂度进行。至少覆盖空输入、单元素、重复值、无解、极端范围，说明是否修改原数组。不要把“背出代码”当成掌握，要能解释循环每一步维护了什么事实。

进阶包括并查集、最短路、前缀树和字符串匹配；根据目标岗位和业务需要继续学习，本页是基础训练入口。
