# 桌面端拖拽与跨平台文件交互实战 (desktop_drop + file_picker + path_provider)

## 使用入口：先解决问题，再做验证

把用户选择或拖入的文件交给业务。

**先做基本操作**：先接收文件并校验类型/大小，验证目标平台权限和目录处理，再做上传与恢复。初次学习可先完成[本模块基础实践](/doc/flutter/Dart与Flutter页面基本使用)。

**再逐步深入**：基本 API 与输入输出 → 常见失败和使用边界 → 场景排查与优化 → 本文机制分析与源码。面试先讲用途和自己的操作过程，再回答场景与原理追问。

随着 Flutter 对 macOS、Windows、Linux 桌面端的全面支持，跨平台相册 App 不仅要满足手机触屏操作，还要具备 PC 端典型的**“鼠标拖拽文件/文件夹批量导入”**与**“调起系统文件管理器精确筛选”**的能力。

## 二、 平台特异性配置（macOS 沙盒避坑）

在 macOS 上，App 默认启用 App Sandbox 隔离。如果不开启文件访问权限，拖拽进来的文件路径会被系统内核拒绝读取（EACCES Permission Denied）。

需在 `macos/Runner/DebugProfile.entitlements` 和 `macos/Runner/Release.entitlements` 中追加：

```xml
<dict>
    <key>com.apple.security.app-sandbox</key>
    <true/>
    <!-- 允许用户选取与拖拽进来的文件具备读写权限 -->
    <key>com.apple.security.files.user-selected.read-write</key>
    <true/>
    <!-- 如需直接选择外接移动硬盘/网络卷中的相册，开启以下权限 -->
    <key>com.apple.security.files.bookmarks.app-scope</key>
    <true/>
</dict>
```

## 三、 桌面端拖拽导入相册组件实战

```dart
// lib/ui/widgets/desktop_file_drop_zone.dart
import 'package:cross_file/cross_file.dart';
import 'package:desktop_drop/desktop_drop.dart';
import 'package:flutter/material.dart';

class DesktopFileDropZone extends StatefulWidget {
  final Widget child;
  final Function(List<XFile> validMediaFiles) onFilesDropped;

  const DesktopFileDropZone({
    super.key,
    required this.child,
    required this.onFilesDropped,
  });

  @override
  State<DesktopFileDropZone> createState() => _DesktopFileDropZoneState();
}

class _DesktopFileDropZoneState extends State<DesktopFileDropZone> {
  bool _isHovering = false;

  // 支持的照片与视频格式拓展名白名单
  static const Set<String> _supportedExtensions = {
    'jpg', 'jpeg', 'png', 'heic', 'webp', 'mp4', 'mov', 'avi'
  };

  @override
  Widget build(BuildContext context) {
    return DropTarget(
      onDragEntered: (detail) => setState(() => _isHovering = true),
      onDragExited: (detail) => setState(() => _isHovering = false),
      onDragDone: (detail) {
        setState(() => _isHovering = false);

        // 过滤文件，剔除非媒体文件（如 txt/zip）
        final validList = detail.files.where((file) {
          final ext = file.name.split('.').last.toLowerCase();
          return _supportedExtensions.contains(ext);
        }).toList();

        if (validList.isNotEmpty) {
          widget.onFilesDropped(validList);
        } else {
          ScaffoldMessenger.of(context).showSnackBar(
            const SnackBar(content: Text('未发现支持的图片或视频文件！')),
          );
        }
      },
      child: Stack(
        children: [
          widget.child,
          // 悬停在窗口上方时的高亮反馈蒙层
          if (_isHovering)
            Positioned.fill(
              child: Container(
                color: Theme.of(context).primaryColor.withValues(alpha: 0.12),
                child: Center(
                  child: Container(
                    padding: const EdgeInsets.symmetric(horizontal: 32, vertical: 20),
                    decoration: BoxDecoration(
                      color: Colors.white,
                      borderRadius: BorderRadius.circular(16),
                      boxShadow: const [
                        BoxShadow(color: Colors.black12, blurRadius: 16, offset: Offset(0, 4))
                      ],
                    ),
                    child: Column(
                      mainAxisSize: MainAxisSize.min,
                      children: const [
                        Icon(Icons.cloud_upload_outlined, size: 48, color: Colors.blueAccent),
                        SizedBox(height: 12),
                        Text(
                          '松开鼠标以批量导入照片到相册',
                          style: TextStyle(fontSize: 16, fontWeight: FontWeight.bold),
                        ),
                      ],
                    ),
                  ),
                ),
              ),
            ),
        ],
      ),
    );
  }
}
```

## 四、 跨平台原生文件管理器调用：`file_picker`

```dart
// 调起原生系统文件选择器
import 'package:file_picker/file_picker.dart';

Future<List<String>> pickLocalMediaFiles() async {
  final FilePickerResult? result = await FilePicker.platform.pickFiles(
    allowMultiple: true,
    type: FileType.custom,
    allowedExtensions: ['jpg', 'png', 'jpeg', 'mp4', 'mov'],
  );

  if (result != null && result.paths.isNotEmpty) {
    return result.paths.whereType<String>().toList();
  }
  return [];
}
```
