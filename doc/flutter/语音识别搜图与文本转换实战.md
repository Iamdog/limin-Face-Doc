# 语音识别搜图与文本转换实战 (speech_to_text)

## 使用入口：先解决问题，再做验证

把用户语音转换成可编辑查询。

**先做基本操作**：先配置麦克风和识别权限，处理启动、停止与结果，验证拒绝/超时/页面退出再接搜索。初次学习可先完成[本模块基础实践](/doc/flutter/Dart与Flutter页面基本使用)。

**再逐步深入**：基本 API 与输入输出 → 常见失败和使用边界 → 场景排查与优化 → 本文机制分析与源码。面试先讲用途和自己的操作过程，再回答场景与原理追问。

在移动相册中，用户积攒了数万张照片后，通过键盘打字搜索（如“2023年去三亚旅游的照片”、“拍猫咪的视频”）操作成本较高。集成 `speech_to_text` 支持按住语音直接识别为关键词，能极大提升相册搜索效率。

## 二、 平台权限与配置

### 1. iOS 权限配置 (`ios/Runner/Info.plist`)
iOS 必须同时声明麦克风和苹果自带的语音识别权限，缺一不可：

```xml
<key>NSMicrophoneUsageDescription</key>
<string>语音搜索照片需要使用您的麦克风进行录音</string>
<key>NSSpeechRecognitionUsageDescription</key>
<string>家庭相册需要调用语音识别引擎将您的语音转换为搜索关键词</string>
```

### 2. Android 权限配置 (`android/app/src/main/AndroidManifest.xml`)
```xml
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.INTERNET" />
```

## 三、 企业级语音搜索服务封装 MVP

```dart
// lib/core/voice/voice_search_manager.dart
import 'package:flutter/foundation.dart';
import 'package:speech_to_text/speech_recognition_result.dart';
import 'package:speech_to_text/speech_to_text.dart';

class VoiceSearchManager {
  static final VoiceSearchManager _instance = VoiceSearchManager._internal();
  factory VoiceSearchManager() => _instance;
  VoiceSearchManager._internal();

  final SpeechToText _speechToText = SpeechToText();
  bool _isInitialized = false;

  /// 初始化语音识别引擎
  Future<bool> initialize() async {
    if (_isInitialized) return true;
    _isInitialized = await _speechToText.initialize(
      onError: (val) => debugPrint('语音识别错误: ${val.errorMsg}'),
      onStatus: (val) => debugPrint('语音识别状态: $val'),
    );
    return _isInitialized;
  }

  /// 开始录音监听并转换
  /// [onWordsChanged]: 实时听写文本流
  /// [onFinalResult]: 用户停顿后最终生成的完整关键词
  Future<void> startListening({
    required Function(String words) onWordsChanged,
    required Function(String finalWords) onFinalResult,
  }) async {
    final available = await initialize();
    if (!available) {
      debugPrint('设备不支持或未授予语音识别权限');
      return;
    }

    await _speechToText.listen(
      localeId: 'zh_CN', // 强制指定识别普通话
      listenFor: const Duration(seconds: 15),
      pauseFor: const Duration(seconds: 3), // 静音 3 秒自动判定说完
      onResult: (SpeechRecognitionResult result) {
        onWordsChanged(result.recognizedWords);
        if (result.finalResult) {
          onFinalResult(result.recognizedWords);
        }
      },
    );
  }

  /// 停止录音
  Future<void> stop() async {
    await _speechToText.stop();
  }

  /// 取消当前识别
  Future<void> cancel() async {
    await _speechToText.cancel();
  }

  bool get isListening => _speechToText.isListening;
}
```

## 四、 交互式语音搜图按钮组件

```dart
// lib/ui/widgets/voice_search_button.dart
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
import 'voice_search_manager.dart';

class VoiceSearchButton extends StatefulWidget {
  final Function(String query) onQuerySubmitted;

  const VoiceSearchButton({super.key, required this.onQuerySubmitted});

  @override
  State<VoiceSearchButton> createState() => _VoiceSearchButtonState();
}

class _VoiceSearchButtonState extends State<VoiceSearchButton> {
  final VoiceSearchManager _voiceManager = VoiceSearchManager();
  bool _isPressing = false;
  String _currentSpoken = '';

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onLongPressStart: (_) async {
        HapticFeedback.mediumImpact(); // 震动触觉反馈
        setState(() {
          _isPressing = true;
          _currentSpoken = '正在倾听中...';
        });

        await _voiceManager.startListening(
          onWordsChanged: (words) {
            setState(() => _currentSpoken = words);
          },
          onFinalResult: (finalWords) {
            if (finalWords.trim().isNotEmpty) {
              widget.onQuerySubmitted(finalWords.trim());
            }
          },
        );
      },
      onLongPressEnd: (_) async {
        setState(() => _isPressing = false);
        await _voiceManager.stop();
      },
      child: AnimatedContainer(
        duration: const Duration(milliseconds: 200),
        padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 8),
        decoration: BoxDecoration(
          color: _isPressing ? Colors.redAccent : Theme.of(context).primaryColor,
          borderRadius: BorderRadius.circular(24),
          boxShadow: _isPressing
              ? [const BoxShadow(color: Colors.redAccent, blurRadius: 12)]
              : [],
        ),
        child: Row(
          mainAxisSize: MainAxisSize.min,
          children: [
            Icon(_isPressing ? Icons.mic : Icons.mic_none, color: Colors.white),
            const SizedBox(width: 8),
            Text(
              _isPressing ? _currentSpoken : '按住说出想要搜索的照片',
              style: const TextStyle(color: Colors.white, fontWeight: FontWeight.bold),
            ),
          ],
        ),
      ),
    );
  }
}
```
