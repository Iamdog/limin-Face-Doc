# 图片缓存与大图缩放画廊实战 (photo_view + cached_network_image + crop)

## 使用入口：先解决问题，再做验证

**先做基本操作**：先按显示尺寸解码，测试加载失败、缓存上限和页面退出，再加入画廊与裁剪。初次学习可先完成[本模块基础实践](/doc/flutter/Dart与Flutter页面基本使用)。

**再逐步深入**：基本 API 与输入输出 → 常见失败和使用边界 → 场景排查与优化 → 本文机制分析与源码。面试先讲用途和自己的操作过程，再回答场景与原理追问。

## 二、 网格图片高速缓存：`cached_network_image` 内存优化封装

> [!WARNING]
> 直接使用 `CachedNetworkImage` 渲染数千张瀑布流图片时，如果不限制解码尺寸，原图直接解压进 GPU 显存会导致极其剧烈的内存暴涨甚至 OOM。必须合理配置 `memCacheWidth` 和 `memCacheHeight`。

```dart
// lib/ui/widgets/optimized_cached_image.dart
import 'package:cached_network_image/cached_network_image.dart';
import 'package:flutter/material.dart';

class OptimizedCachedImage extends StatelessWidget {
  final String imageUrl;
  final double? width;
  final double? height;
  final BoxFit fit;

  const OptimizedCachedImage({
    super.key,
    required this.imageUrl,
    this.width,
    this.height,
    this.fit = BoxFit.cover,
  });

  @override
  Widget build(BuildContext context) {
    return CachedNetworkImage(
      imageUrl: imageUrl,
      width: width,
      height: height,
      fit: fit,
      // 核心：限制进入 Flutter 图像缓存的解码像素尺寸，降维打击 OOM
      memCacheWidth: width != null ? (width! * 2).toInt() : 600,
      memCacheHeight: height != null ? (height! * 2).toInt() : 600,
      placeholder: (context, url) => Container(
        color: Colors.grey[200],
        child: const Center(
          child: SizedBox(
            width: 24,
            height: 24,
            child: CircularProgressIndicator(strokeWidth: 2),
          ),
        ),
      ),
      errorWidget: (context, url, error) => Container(
        color: Colors.grey[100],
        child: const Icon(Icons.broken_image, color: Colors.grey, size: 32),
      ),
    );
  }
}
```

## 三、 全屏手势缩放画廊：`photo_view` + `PhotoViewGallery`

支持双指缩放、双击放大、横向手势平滑切换照片：

```dart
// lib/ui/pages/gallery_preview_page.dart
import 'package:cached_network_image/cached_network_image.dart';
import 'package:flutter/material.dart';
import 'package:photo_view/photo_view.dart';
import 'package:photo_view/photo_view_gallery.dart';

class GalleryPreviewPage extends StatefulWidget {
  final List<String> imageUrls;
  final int initialIndex;

  const GalleryPreviewPage({
    super.key,
    required this.imageUrls,
    this.initialIndex = 0,
  });

  @override
  State<GalleryPreviewPage> createState() => _GalleryPreviewPageState();
}

class _GalleryPreviewPageState extends State<GalleryPreviewPage> {
  late int currentIndex;

  @override
  void initState() {
    super.initState();
    currentIndex = widget.initialIndex;
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: Colors.black,
      body: Stack(
        children: [
          // 1. 画廊构建器
          PhotoViewGallery.builder(
            itemCount: widget.imageUrls.length,
            pageController: PageController(initialPage: widget.initialIndex),
            onPageChanged: (index) => setState(() => currentIndex = index),
            builder: (context, index) {
              return PhotoViewGalleryPageOptions(
                imageProvider: CachedNetworkImageProvider(widget.imageUrls[index]),
                minScale: PhotoViewComputedScale.contained * 0.8,
                maxScale: PhotoViewComputedScale.covered * 3.0, // 支持放大到 3 倍
                heroAttributes: PhotoViewHeroAttributes(tag: widget.imageUrls[index]),
              );
            },
            loadingBuilder: (context, event) => const Center(
              child: CircularProgressIndicator(color: Colors.white60),
            ),
          ),

          // 2. 顶部工具栏（返回键 + 当前张数指示）
          Positioned(
            top: 48,
            left: 16,
            right: 16,
            child: Row(
              mainAxisAlignment: MainAxisAlignment.spaceBetween,
              children: [
                IconButton(
                  icon: const Icon(Icons.close, color: Colors.white, size: 28),
                  onPressed: () => Navigator.pop(context),
                ),
                Text(
                  '${currentIndex + 1} / ${widget.imageUrls.length}',
                  style: const TextStyle(color: Colors.white, fontSize: 16, fontWeight: FontWeight.bold),
                ),
                const SizedBox(width: 48), // 占位对称
              ],
            ),
          ),
        ],
      ),
    );
  }
}
```

## 四、 纯 Dart 头像/相册封面裁剪：`crop_your_image`

无需通过复杂且容易崩溃的原生平台通道，使用纯 Dart 实现精确裁剪：

```dart
// lib/ui/widgets/avatar_cropper_dialog.dart
import 'dart:typed_data';
import 'package:crop_your_image/crop_your_image.dart';
import 'package:flutter/material.dart';

class AvatarCropperDialog extends StatefulWidget {
  final Uint8List imageBytes;
  final Function(Uint8List cropped) onCropped;

  const AvatarCropperDialog({
    super.key,
    required this.imageBytes,
    required this.onCropped,
  });

  @override
  State<AvatarCropperDialog> createState() => _AvatarCropperDialogState();
}

class _AvatarCropperDialogState extends State<AvatarCropperDialog> {
  final CropController _cropController = CropController();

  @override
  Widget build(BuildContext context) {
    return Dialog.fullscreen(
      child: Scaffold(
        appBar: AppBar(
          title: const Text('裁剪封面/头像'),
          actions: [
            IconButton(
              icon: const Icon(Icons.check),
              onPressed: () => _cropController.crop(), // 触发裁剪
            ),
          ],
        ),
        body: Crop(
          image: widget.imageBytes,
          controller: _cropController,
          aspectRatio: 1.0, // 强制 1:1 正方形裁剪
          withCircleUi: true, // 圆形头像引导遮罩
          onCropped: (cropped) {
            widget.onCropped(cropped);
            Navigator.pop(context);
          },
        ),
      ),
    );
  }
}
```
