# 相册多选与相机采集实战 (wechat_assets_picker & wechat_camera_picker)

## 使用入口：先解决问题，再做验证

安全取得用户选择或拍摄的媒体。

**先做基本操作**：先申请所需权限并设置数量限制，处理取消/有限相册授权，再验证文件可达性和上传。初次学习可先完成[本模块基础实践](/doc/flutter/Dart与Flutter页面基本使用)。

**再逐步深入**：基本 API 与输入输出 → 常见失败和使用边界 → 场景排查与优化 → 本文机制分析与源码。面试先讲用途和自己的操作过程，再回答场景与原理追问。

在移动端相册应用（如家庭相册、图片社交、内容发布）中，直接调用系统原生 Picker 往往存在交互割裂、UI 无法定制、无法混合多选图片视频等痛点。`wechat_assets_picker` 和 `wechat_camera_picker` 提供了完全对标微信的高性能相册多选与相机拍摄体验。

## 二、 平台权限与底层配置（避坑关键）

### 1. iOS 权限配置 (`ios/Runner/Info.plist`)
相册和相机涉及多项敏感隐私权限，必须在 `Info.plist` 中声明文案，否则提审必被拒，运行时直接 Crash：

```xml
<key>NSPhotoLibraryUsageDescription</key>
<string>家庭相册需要访问您的相册，以便选择和上传照片与视频</string>
<key>NSPhotoLibraryAddUsageDescription</key>
<string>家庭相册需要将照片保存至您的系统相册</string>
<key>NSCameraUsageDescription</key>
<string>家庭相册需要使用相机进行拍照和录制视频</string>
<key>NSMicrophoneUsageDescription</key>
<string>录制视频时需要使用麦克风录制声音</string>
```

### 2. Android 权限适配 (`android/app/src/main/AndroidManifest.xml`)
针对 **Android 13+ (API 33)** 的细粒度媒体权限变更，需同时适配新旧系统：

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <!-- 相机与录音 -->
    <uses-permission android:name="android.permission.CAMERA" />
    <uses-permission android:name="android.permission.RECORD_AUDIO" />

    <!-- Android 12 及以下 -->
    <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" android:maxSdkVersion="32" />
    <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" android:maxSdkVersion="29" />

    <!-- Android 13+ 细粒度媒体权限 -->
    <uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
    <uses-permission android:name="android.permission.READ_MEDIA_VIDEO" />
    <uses-permission android:name="android.permission.READ_MEDIA_AUDIO" />
</manifest>
```

## 三、 企业级封装实战

```dart
// lib/core/media/asset_picker_service.dart
import 'package:flutter/material.dart';
import 'package:wechat_assets_picker/wechat_assets_picker.dart';
import 'package:wechat_camera_picker/wechat_camera_picker.dart';

class AssetPickerService {
  /// 唤起多选相册
  /// [maxAssets]: 最多选择数量，默认 9 张
  /// [requestType]: 资产类型，默认图片与视频混选 (RequestType.common)
  static Future<List<AssetEntity>?> selectAssets(
    BuildContext context, {
    int maxAssets = 9,
    List<AssetEntity>? selectedAssets,
    RequestType requestType = RequestType.common,
  }) async {
    final List<AssetEntity>? result = await AssetPicker.pickAssets(
      context,
      pickerConfig: AssetPickerConfig(
        maxAssets: maxAssets,
        selectedAssets: selectedAssets,
        requestType: requestType,
        themeColor: Theme.of(context).primaryColor,
        textDelegate: const AssetPickerTextDelegate(),
        specialPickerType: SpecialPickerType.noPreview, // 小图快速勾选体验
        filterOptions: FilterOptionGroup(
          imageOption: const FilterOption(
            needTitle: true,
            sizeConstraint: SizeConstraint(ignoreSize: true),
          ),
          videoOption: const FilterOption(
            durationConstraint: DurationConstraint(
              max: Duration(minutes: 5), // 限制视频不超过 5 分钟
            ),
          ),
        ),
      ),
    );
    return result;
  }

  /// 唤起仿微信拍摄（支持拍照与长按录像）
  static Future<AssetEntity?> captureMedia(BuildContext context) async {
    final AssetEntity? entity = await CameraPicker.pickFromCamera(
      context,
      pickerConfig: const CameraPickerConfig(
        enableRecording: true, // 开启长按录像
        maximumRecordingDuration: Duration(seconds: 30), // 最长录制 30 秒
        themeColor: Colors.amber,
        resolutionPreset: ResolutionPreset.high,
      ),
    );
    return entity;
  }
}
```

## 四、 资产实体 `AssetEntity` 转本地文件

获取到 `AssetEntity` 后，若需上传或传给压缩库，需转为沙盒 `File`：

```dart
// 将 AssetEntity 异步转为沙盒临时 File
Future<File?> getFileFromEntity(AssetEntity entity) async {
  // 原图原文件（大图、原始视频）
  final File? originalFile = await entity.originFile;
  
  // 或者获取缩略图预览（极大节省内存）
  // final Uint8List? thumbData = await entity.thumbnailDataWithSize(const ThumbnailSize(200, 200));

  return originalFile;
}
```

## 五、 高频生产避坑

1. **iOS Limited Photos 授权死锁**：iOS 14+ 允许用户仅授权「所选照片」。`wechat_assets_picker` 内部已实现 `PhotoManager.presentLimited()` 触发系统重选弹窗，无需自写引导代码。
2. **Android 混淆规则**：如启用 R8/Proguard，若出现类找不到崩溃，需在 `proguard-rules.pro` 中追加规则：
   ```text
   -keep class com.github.panpf.sketch.** { *; }
   -keep class com.yalantis.ucrop.** { *; }
   ```
