# 视频播放与视口滚动联播实战 (video_player + visibility_detector)

## 使用入口：先解决问题，再做验证

在滚动列表中控制播放与资源。

**先做基本操作**：先初始化/播放/暂停/释放单个播放器，验证前后台，再加入视口控制与数量上限。初次学习可先完成[本模块基础实践](/doc/flutter/Dart与Flutter页面基本使用)。

**再逐步深入**：基本 API 与输入输出 → 常见失败和使用边界 → 场景排查与优化 → 本文机制分析与源码。面试先讲用途和自己的操作过程，再回答场景与原理追问。

在现代相册和内容流（Feed 流）中，视频与照片往往混排展示。为了提供类似小红书/抖音的沉浸体验，需要实现：**滚动到当前视频露出超过特定阈值时自动静音起播，滑出视口立即暂停释放硬件解码器**。

## 一、 核心依赖与版本避坑

```yaml
dependencies:
  # 官方原生视频播放插件，配合 visibility_detector 做滚动可见即播
  video_player: 2.11.1
  visibility_detector: ^0.4.0+2

dependency_overrides:
  # Xcode 26 无法解析 2.12.x 引入的 Obj-C 显式模块辅助库
  # 强制覆盖为 2.10.0，保持上层 Dart API 100% 兼容同时规避 CocoaPods 构建失败
  video_player_avfoundation: 2.10.0
```

> [!WARNING]
> **Xcode 26 构建崩溃避坑**：`video_player` 2.12.x 版本在 macOS/iOS 原生层中增加了 `video_player_avfoundation_objc` 模块。在开启显式模块检查（Explicit Modules Validation）的新版 Xcode 下会出现符号丢失错误。通过上述 `dependency_overrides` 锁定底层的原生实现插件，是目前最稳健的企业级生产方案。

## 二、 视口感知自动播放组件封装

```dart
// lib/ui/widgets/feed_auto_video_player.dart
import 'dart:io';
import 'package:flutter/material.dart';
import 'package:video_player/video_player.dart';
import 'package:visibility_detector/visibility_detector.dart';

class FeedAutoVideoPlayer extends StatefulWidget {
  final String videoSource; // 本地路径或远程 URL
  final String itemKey;

  const FeedAutoVideoPlayer({
    super.key,
    required this.videoSource,
    required this.itemKey,
  });

  @override
  State<FeedAutoVideoPlayer> createState() => _FeedAutoVideoPlayerState();
}

class _FeedAutoVideoPlayerState extends State<FeedAutoVideoPlayer> {
  late VideoPlayerController _controller;
  bool _isInitialized = false;

  @override
  void initState() {
    super.initState();
    _initPlayer();
  }

  void _initPlayer() {
    _controller = widget.videoSource.startsWith('http')
        ? VideoPlayerController.networkUrl(Uri.parse(widget.videoSource))
        : VideoPlayerController.file(File(widget.videoSource));

    _controller.initialize().then((_) {
      if (!mounted) return;
      setState(() => _isInitialized = true);
      _controller.setLooping(true);
      _controller.setVolume(0); // 默认静音自动起播，避免多视频音量轰炸
    });
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return VisibilityDetector(
      key: Key('feed-video-${widget.itemKey}'),
      onVisibilityChanged: (VisibilityInfo info) {
        if (!_isInitialized) return;

        // 露出视口比例 >= 75% 且当前暂停状态 -> 自动起播
        if (info.visibleFraction >= 0.75) {
          if (!_controller.value.isPlaying) {
            _controller.play();
          }
        } else {
          // 露出视口比例 < 75% -> 立即暂停
          if (_controller.value.isPlaying) {
            _controller.pause();
          }
        }
      },
      child: AspectRatio(
        aspectRatio: _isInitialized ? _controller.value.aspectRatio : 16 / 9,
        child: Stack(
          alignment: Alignment.center,
          children: [
            _isInitialized
                ? VideoPlayer(_controller)
                : const Center(child: CircularProgressIndicator(strokeWidth: 2)),

            // 右下角静音/开音切换按钮
            if (_isInitialized)
              Positioned(
                right: 8,
                bottom: 8,
                child: GestureDetector(
                  onTap: () {
                    final isMuted = _controller.value.volume == 0;
                    _controller.setVolume(isMuted ? 1.0 : 0);
                    setState(() {});
                  },
                  child: Container(
                    padding: const EdgeInsets.all(6),
                    decoration: BoxDecoration(
                      color: Colors.black54,
                      borderRadius: BorderRadius.circular(20),
                    ),
                    child: Icon(
                      _controller.value.volume == 0 ? Icons.volume_off : Icons.volume_up,
                      color: Colors.white,
                      size: 18,
                    ),
                  ),
                ),
              ),
          ],
        ),
      ),
    );
  }
}
```

## 三、 高性能治理与高频生产陷阱

1. **Android 原生硬件解码器数量上限（Codec Starvation）**：低端 Android 机器同时运行的硬件解码器实例通常仅有 4~16 个。在海量视频的长列表中，千万不要为每个 item 都长久保留未初始化的 Controller，滑出视口数屏的非活跃视频必须及时 `dispose()` 并在滑回时懒加载。
2. **黑屏闪烁防护**：在 `_controller.initialize()` 完成前，上层应展示视频封面缩略图（由后端返回或客户端通过原图提取），待 `_isInitialized` 为 true 并触发首帧渲染后再淡入显示视频 Widget。
