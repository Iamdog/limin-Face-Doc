# MySQL 阶梯式全景知识库与阅读地图

## 一、设计理念：由浅入深、阶梯进阶

本专题知识库针对一线互联网技术团队与大厂技术对标（阿里 P5~P8、腾讯 8~12 级）倾力打造，彻底解决“开局就是深水源码、初学者望而生畏”或者“通篇浅显语法、无法支撑社招连环追问”的断层痛点。

知识库采用**严格的五级梯队演进架构**：
- **初级筑基（0~2年 / 校招筑基）**：从零基础客户端连接配置、SQL 语言分类（DDL/DML/DQL/DCL）、核心数据类型选型规范、表完整性约束、单表/分组/多表连接查询基础、事务基本控制到新手常见报错排查 SOP，扫清新手上路与基础开发盲区；
- **中级进阶（2~4年 / 独立骨干）**：深入 SQL 逻辑执行顺序、多表关联嵌套循环算法（NLJ/BNLJ/Hash Join）、B+ 树物理结构与容量估算、索引分类与覆盖索引、索引失效十大黄金法则、`EXPLAIN` 执行计划全字段拆解、`optimizer_trace` 成本推导、千万级深分页优化与高并发大字段建表规范；
- **高级深水（3~5年+ / 核心攻坚）**：下钻 InnoDB 物理存储引擎内核，深度拆解 16KB 数据页物理组织、Page Directory 二分查找、行溢出处理（Compact vs Dynamic）、Redo Log / Undo Log / Binlog 协同机制、两阶段提交（2PC）与 Crash-Safe 崩溃恢复、Buffer Pool 冷热分离 LRU、MVCC 版本链与 ReadView 时序、全局锁/MDL 锁与 Next-Key Lock 全场景加锁判定与死锁根治；
- **资深架构（5年+ / 架构专家）**：主从复制底层原理与主从延迟 6 大根因及破局方案、高可用架构 Orchestrator 与组复制 MGR 选型、分库分表 ShardingSphere 与分片键设计、分布式事务（XA、Seata AT、Saga、本地消息表）、大表无锁 DDL（gh-ost / pt-osc）、高性能连接池 HikariCP 调优、MySQL 8.0 窗口函数与 Instant DDL、生产级 APM 监控大盘与慢 SQL 治理体系；
- **全阶段真题库（150 道硬核对标）**：拆分为初级 50 题、中级 50 题、高级资深 50 题三套标准通关真题，直击社招与大厂必考高频连环炮。

## 三、面试与学习实战建议

```mermaid
flowchart LR
    A["初级筑基<br/>(语法/约束/分组/事务)"] --> B["中级进阶<br/>(索引/JOIN/EXPLAIN/深分页)"]
    B --> C["高级深水<br/>(页结构/MVCC/Crash-Safe/锁)"]
    C --> D["资深架构<br/>(高可用/主从延迟/分库分表/APM)"]
    D --> E["150道大厂真题<br/>(全面通关)"]
```
